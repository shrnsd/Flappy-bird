# Flappy Bird

A simple, full-screen Flappy Bird game built using HTML, CSS, and JavaScript.

### Features
- Full-screen gameplay
- Custom character image upload
- Custom jump and game-over sounds
- High-score tracking
- Animated score celebrations
- Keyboard and mouse controls

### How to Play
Open `flappy_bird_full_screen.html` in your browser and click **Start Game**.

**Controls:** Space, W, Up Arrow, or Mouse Click.

### Technologies
HTML, CSS, JavaScript, Canvas API and Web Audio API.
